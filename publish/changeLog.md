车机（Android 6 及以上）深度适配：修复 2G 内存车机搜索闪退、切换主题闪退，错误日志改走 443 HTTPS 中转，发布包精简。

### 优化

- **低内存渲染优化**：内置主题背景图降采样转 JPEG（累计减小约 7.5MB）；背景图按视图尺寸解码，低内存车机自动关闭动态背景模糊；封面图按视图降采样，系统内存紧张时自动释放图片缓存
- **2G 内存车机搜索优化**：关闭搜索结果列表的原生裁剪（规避列表快速替换崩溃）；单次网络响应限制 8MB；「全部音源」低内存串行搜索；相似度排序截断超长字符串
- **2G+32G 深度适配**：错误日志超 1MB 自动轮转，查看/上报只读尾部，长期开机不再 OOM；主题/语言/自定义 API 启动并行初始化，缩短冷启动；发布包剔除 x86/x86_64，仅 ARM 双架构 + universal
- **错误/崩溃/ANR 日志收集**：操作面包屑（含内存/存储快照）、主线程看门狗、进程退出原因、未处理 Promise 记录，启动时并入「设置-错误日志」并自动上报，车机无需抓 logcat
- **面包屑降噪**：memory.trim 只记关键级别；低内存车机上这些级别也是常态，按级别 1 小时限频 1 条（超出以 +N 标注），启动后 60s 内调度事件忽略，日志不再被高频 trim 刷屏
- **仓库瘦身**：移除失效 submodule、iconv-lite 依赖、虾米/百度音源死代码、上游遗留调试脚本与注释代码（约 -1500 行）

### 修复

- **切换主题闪退**：主题数据校验与回退 + 页面级错误边界 + 监听器泄漏修复，渲染异常仅降级当前页面
- **中转反馈“上传失败”**：443 HTTPS 中转优先（车机网络常封非标 SSH 端口），SSH/直连兜底；修复 SSH 退出码竞态；限流给出友好提示，上报附带设备内存信息
